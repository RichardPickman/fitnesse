# Fitnesse — Development Rules

## Committing & PR

1. **Show diff before every commit** — never commit blind. Always present the diff for review.
2. **Commit per ticket** — each commit message starts with the ticket number: `002: Supabase exercise library setup`.
3. **Push as PR** — after each ticket, push to a feature branch and open as a PR, unless the user says otherwise.
4. **Ask before script execution** — no `npm test`, `npx tsc`, etc. without showing the command first.
